# AGENTS.md

## Cursor Cloud specific instructions

### Overview

Oud Atlas is a Next.js 14 (App Router) fragrance directory and community platform. It is a single self-contained app with no external service dependencies — all data comes from a static JSON file (`src/data/fragrances.json`).

### Stack

- **Runtime**: Node.js >= 18
- **Framework**: Next.js 14 (App Router), React 18, TypeScript 5
- **Styling**: Tailwind CSS 3.4
- **Package manager**: npm (lockfile: `package-lock.json`)

### Common commands

| Task | Command |
|------|---------|
| Install deps | `npm install` |
| Dev server | `npm run dev` (serves on `localhost:3000`) |
| Lint | `npm run lint` |
| Build | `npm run build` |

### Notes

- No database, auth, or external APIs are required at runtime.
- The scraper scripts under `scripts/` are optional utilities (require Playwright) and are not needed for normal development.
- The `artifacts/` directory contains pre-existing screenshots and videos from earlier development — these are committed assets, not generated by the build.
- Images are loaded from remote URLs; `next.config.mjs` allows all remote hostnames via a wildcard pattern.
